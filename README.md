# python-ds-and-algorithms
Python implementations of core data structures and caching algorithms ( LRU, LFU, TTL, Min-Heap)

Custom implementations focused on foundational efficiency and design.

## Features 
* **LRU & LFU Caches:** Custom cache implementations with access tracking.
* **Timed Cache:** TTL-based cache eviction system.
* **Binary Min-Heap:** Complete binary tree representation using Python lists.
